Confluence created Apr 24, 2026 (v1) — "Publicly Available Files" — 11 functional requirements around auto-sharing: when a vendor attaches a file to an Observation, view-only access is auto-granted to all monitoring orgs without manual permission management. Figma covers the upload/vault UI but not the permission/audit layer.

  • Not in scope: granular permissions, file access expiration, email/in-app notifications on file changes
