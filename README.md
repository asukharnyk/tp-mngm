# TP Features — Design-to-Requirements Checklist

**Live page:** https://asukharnyk.github.io/tp-mngm/figma-confluence-checklist.html

A weekly-updated tracker that compares what is designed in Figma against what is specified in Confluence — for 7 active TP platform features.

## What it shows

For each feature you get:
- **Figma + Confluence + Jira links** in one place
- **Progress bar** — how many requirements are covered in Figma (e.g. 10/16 · 62%)
- **Done column** — screens and flows already designed
- **Missing column** — requirements not yet reflected in Figma
- **DS Compliance** — design system audit (critical issues, warnings, % score)

## How to use

- Use the **sidebar filters** to show only features with updates, gaps, or missing requirements
- Click any **Figma / Confluence / Jira** pill to jump directly to the source
- Expand **DS Compliance** at the bottom of each card for component audit details

## Updates

Refreshed automatically every **Monday at 9:00 AM** — Confluence versions and Figma dates are pulled fresh each run. A Slack DM is sent after each update.
